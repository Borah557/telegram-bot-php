# Simple Telegram Bot in PHP

This is a simple Telegram bot written in PHP that echoes back messages.

## Setup

1. Create a new bot with [BotFather](https://t.me/BotFather) and get your API token
2. Clone this repository
3. Copy `config.example.php` to `config.php` and fill in your bot token
4. Deploy to your hosting provider
